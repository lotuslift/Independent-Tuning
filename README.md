# Independent-Tuning

A gauge connection’s field strength and its holonomy are not the same fact told twice. We exhibit an explicit SO(2) connection on Rt × S1θ × Rx × Ry with a genuine Lorentzian metric, and prove two independence results by direct computation, not analogy. First: the Maxwell curvature is fixed entirely by a free function f of retarded time, while the holonomy around the compact fiber is fixed entirely by an unrelated real parameter a — one is a local differential fact, the other a global integral fact, and the construction sets them to arbitrary independent values simultaneously. Second: on the same background, two worldlines with the same endpoints in coordinate time carry different proper times while carrying independently specifiable holonomy — curvature-free local geometry and global phase transport are not the same measurement wearing two names. There is no interpretation attached to either result beyond what the equations say.
